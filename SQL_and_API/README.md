# Testing of Database and Public API (PostgreSQL & Reqres)

## Project Description
This mini project shows basic QA skills in working with databases and API testing.  
It includes simple SQL queries in PostgreSQL using DBeaver and testing of the public Reqres API using Postman.

The goal is to demonstrate understanding of database structure, basic queries, and API request/response checking.

## Scope of Testing
- Working with PostgreSQL database (simple SELECT, INSERT, UPDATE, DELETE queries)
- Checking data in database tables
- Testing public API https://reqres.in
- Checking API responses (status codes and response body)
- Using Postman for manual tests making queries.

## Tools Used
- PostgreSQL 18
- DBeaver 25.3.0
- Postman v11.74.4
- Reqres.in (public API)
- Google Sheets / Notepad — for test cases, bug reports, and documentation
- GitHub — for storing artifacts

## Environment and Devices
- PC with Windows 10 Pro

## Types of Testing
- Functional testing
- API testing
- Database testing
- Negative testing

## Testing Focus
- Correct work of SQL queries
- Checking that data in database is correct
- Verifying API status codes (200, 201, 400, 404)
- Checking JSON response structure
