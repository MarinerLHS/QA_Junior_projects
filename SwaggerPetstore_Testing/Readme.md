# Testing of public API Swagger petstore 

## Project Description
Swagger petstore is a public API that allows users to make different tests and learn how API works. Tests are running by using a Postman application. Checklist, test cases and bug reports forms will be created in Jira task tracker.

## Scope of Testing
- Testing of public API Swagger.io 
- Survey of API responses and requests 
- Using posibilities of Postman in auto-tests
- Using of Jira task tracker for test cases and bug reports

## Tools Used
- Postman  v11.77.2;
- Swagger.io
- Jira 

## Environment and Devices
- Laptop with Windows 10 Pro

## Types of Testing
- Functional testing
- Negative testing
- Network testing
- End-to-End testing

## Testing Focus
Testing focused on how API works. Observation of response codes to see how public API reacts on different data. 

## Test Artifacts
- Checklist
- Test cases
